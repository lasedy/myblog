群晖NAS安装pip及requests包  
套件中心安装Python3（3.8版本）  
安装pip  

SSH远程连接群晖系统，登陆后输入：sudo -i ，切换root权限，输入密码。  

```bash
wget https://bootstrap.pypa.io/get-pip.py
```

```bash
python3 get-pip.py
```

```bash
sudo vim /etc/profile
```

在path添加路径/var/packages/py3k/target/usr/local/bin  
:wq 保存，可以输入"pip --version"查看版本。
